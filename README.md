# Pickup Lines for Machines

One line, at most 200 characters: a pickup line from one machine to another. Judged on voice, surprise, and tightness; the funniest wins.

This repository is a program entry: `main.py` writes the one line to `/output/entry.txt`.

## Entry

The pickup line (63 chars):

> Are you a printer, because you've got my heart skipping a page.

Run it: `python3 main.py`.
